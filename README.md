# 酒店遗留物保管与认领系统

保洁登记客房遗留物，前台按住客描述搜索、核实失主身份并办理自取 / 代领 / 寄送，
每件物品从发现到出库的每次交接都记录在**只追加**台账中。

- 后端：Go + Gin + GORM + SQLite（照片保存在本地磁盘）
- 前端：Vue 3 + Vue Router + Vite（构建后由 Go 内嵌托管）
- 寄送通知：模拟接口（生成 `MOCK` 单号并落库、写台账）

## 一条命令启动

```bash
./run.sh
```

首次运行会自动构建前端（需要 Node.js）和后端（需要 Go 1.23+），随后在
**http://localhost:8080** 同时提供页面与 API。之后重启无需再次构建前端。

运行数据均在 `backend/data/`：`lostfound.db` 台账库与 `uploads/` 照片目录。

## 业务流程与规则

1. **保洁登记**：房号、发现时间、照片（本地保存）、封袋号、保管位置、保管天数（默认 90 天）。
   证件 / 现金为敏感物品，需填写"对外必要信息"。
2. **前台搜索**：按住客描述 / 房号 / 封袋号搜索。证件与现金在列表中只显示必要信息，
   完整证件号、金额不随列表返回，详情页也仅前台可见。
3. **物品页面**：按时间展示保管位置、经手员工、认领状态的完整交接链。
4. **身份核实**：一件物品可有多位认领人，分别核实、互不影响；驳回不影响其他人。
5. **代领授权**：仅已核实的失主可授权，授权可撤销、有有效期；**撤销 / 过期 / 已使用后不能代领**，
   到场代领人姓名证件必须与授权一致。
6. **暂停交付**：出库现场封签与封袋号不符、或超过保管期，自动登记暂停（记录落库），
   暂停解除前一律不能出库；超期需酒店审批延期。
7. **出库**：本人自取 / 代领 / 寄送。一件物品全库只能成功出库一次。
8. **台账只追加**：交接记录按物品内序号 `seq` 连续递增；SQLite 触发器在数据库层禁止
   UPDATE / DELETE。

## 并发与一致性设计

- SQLite 开启 WAL，连接池限制为单连接，出库写事务在连接层面串行化；
- `deliveries.item_id` 唯一索引 + 物品状态条件更新（`WHERE status <> 'released'`）双重兜底，
  两名前台同时确认出库时**恰好一个成功，另一个收到 409**，不会重复交给不同人；
- 封签不符 / 超期等暂停记录在事务内先提交再返回冲突错误，保证拦截事件不被回滚丢失。

## 验证

```bash
# Go 层集成测试（含 race 检测，无需启动服务）
cd backend && go test ./tests/ -v

# 真实 HTTP 端到端验证（自动编译、起停服务、临时数据目录）
python3 scripts/verify_e2e.py
```

端到端脚本覆盖：重复认领核实、双员工并发出库、授权撤销后的代领拦截、冒名代领拦截、
封签不符暂停、超期暂停与延期、脱敏搜索，共 28 项断言。

## 主要接口

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/auth/login` | - | 登录获取 Token |
| POST | `/api/items` | 保洁 | multipart 登记（含照片） |
| GET | `/api/items?q=&category=` | 员工 | 脱敏搜索 |
| GET | `/api/items/:id` | 员工 | 详情 + 交接时间线 + 认领/授权/出库 |
| POST | `/api/items/:id/move` | 员工 | 变更保管位置（追加台账） |
| POST | `/api/items/:id/claims` | 前台 | 登记认领人 |
| POST | `/api/claims/:id/verify` | 前台 | 核实通过 / 驳回 |
| POST | `/api/claims/:id/authorization` | 前台 | 建立代领授权 |
| POST | `/api/authorizations/:id/revoke` | 前台 | 撤销授权（立即生效） |
| POST | `/api/items/:id/release` | 前台 | 出库（自取/代领/寄送，封签核验） |
| POST | `/api/holds/:id/resolve` | 前台 | 解除暂停（可延长保管期） |
| GET | `/api/items/:id/notifications` | 员工 | 模拟寄送通知记录 |
